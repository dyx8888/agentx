# 异常检测与告警

## 执行流程

### 步骤1：阈值设定
根据历史数据自动计算告警阈值（均值±2标准差），或使用公司自定义阈值。

### 步骤2：实时监控
对每项指标按5分钟粒度检查：
- GMV 环比变化 vs 阈值
- ROI vs 盈亏平衡线
- CTR/CVR vs 行业均值
- 退货率 vs 历史均值
- 库存周转 vs 安全线

### 步骤3：异常分级
- **红色（紧急）**：GMV下降>20% / ROI跌破盈亏线 / 退货率飙升至>10%
- **橙色（重要）**：CTR下降>50% / 库存超30天 / 退款率异常
- **黄色（关注）**：轻微偏离阈值但持续2h以上

### 步骤4：归因分析
对于触发的告警，自动运行 attribution_analysis：
1. 流量来源是否变化
2. 转化漏斗哪环节出问题
3. 竞争对手是否有动作
4. 是否平台活动影响

### 步骤5：告警推送
1. Dashboard → WebSocket 实时推送
2. 相关Agent → 上下文注入（红色级别）
3. 企业微信/钉钉 → 即时消息推送

## 输出规范
告警信息：级别+指标+偏离幅度+可能原因+建议措施+推送目标。

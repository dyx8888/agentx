# 经营表现分析

## 执行流程

### 步骤1：数据确认
确认分析时间范围、数据来源（抖店/淘宝/拼多多/全部）、分析维度（整体/按平台/按商品/按达人）。

### 步骤2：核心指标计算
调用 calculate_metrics 计算：
- GMV、订单量、客单价、退款率
- ROI、CPA、CTR、CVR、GPM
- 环比/同比变化率
- 各平台/各渠道贡献占比

### 步骤3：趋势分析
1. 按日/周/月维度画趋势线
2. 标注异常波动点
3. 分析波动原因（活动/竞品/季节/价格调整）

### 步骤4：归因分解
1. 销量变化 = 流量变化 + 转化率变化 + 客单价变化
2. ROI变化 = GMV变化 + 投放费用变化
3. 逐层拆解到可执行层面

### 步骤5：优化建议
按优先级输出：P0紧急/P1重要/P2优化

## 输出规范
结构化分析报告：摘要→核心指标→趋势分析→归因分解→优化建议。

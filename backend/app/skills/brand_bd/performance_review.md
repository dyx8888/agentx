# 达人合作效果复盘

## 执行流程

### 步骤1：数据收集
调用 generate_performance_report 获取合作数据：播放量/互动量/GMV/ROI/CPM/GPM。

### 步骤2：多维度分析
1. 达人维度：互动率排名、粉丝增长、内容质量评分
2. 内容维度：爆款内容特征、高转化内容特征、低效内容原因
3. 商品维度：爆款单品、连带购买率、退货率
4. 人群维度：实际触达人群vs目标人群匹配度

### 步骤3：ROI归因分析
1. 直接ROI = GMV / 投放费用
2. 间接ROI = (GMV + 自然流量GMV增量 - 自然衰减) / 投放费用
3. 品牌价值 = 曝光价值 + 内容资产沉淀 + 粉丝增长价值

### 步骤4：改进建议
1. 达人选择优化：哪些类型达人ROI最高
2. 内容方向优化：哪种内容形式转化最好
3. 费用优化：不同量级达人最佳费用区间

## 输出规范
结构化复盘报告：核心指标速览→达人表现排名→内容效果分析→费用效率分析→改进建议。

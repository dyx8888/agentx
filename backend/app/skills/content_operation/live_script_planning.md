# 直播脚本策划

## 执行流程

### 步骤1：直播方案确认
确认：直播主题、产品清单（含价格/卖点）、直播时长、目标GMV、主播风格。

### 步骤2：直播流程设计（按时间线）
1. **开场（0-5分钟）**：欢迎语+直播间福利预告+关注引导
2. **产品讲解轮次（每15-20分钟一轮）**：
   - 产品引入（痛点/场景）→ 产品展示 → 核心卖点 → 价格公布 → 限时福利 → 促单 → 互动解答
3. **互动环节**：每30分钟抽奖/问答/投票
4. **结尾**：限时倒计时+明日预告+感谢粉丝

### 步骤3：单品讲解话术
每款产品输出完整讲解话术：
1. 痛点引入（2分钟）
2. 产品展示+卖点讲解（5分钟）
3. 价格与福利公布（3分钟）
4. 促单+限时引导（5分钟）

### 步骤4：应急话术准备
- 冷场话术
- 负面评论应对
- 价格争议应对
- 技术故障应对

## 输出规范
完整直播脚本：流程总览+每阶段话术+单品讲解卡+互动游戏方案+应急话术库。

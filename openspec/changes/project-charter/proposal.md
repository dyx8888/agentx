## Why

国内电商公司（淘宝/天猫/抖音/拼多多/小红书商家）普遍面临人力成本高、专业人才难招、多岗位协作效率低的问题。一个中型电商团队通常需要品牌商务、内容运营、数据分析、客服、仓储物流、视觉设计、供应链选品、智能投流等多个角色协同工作，但中小企业往往无力组建完整团队。

AgentX 用 AI 数字员工替代传统电商职位，让企业主以远低于人力成本的投入获得一个完整的虚拟电商团队。但我们的目标不仅仅是「减少成本」——更重要的是通过 AI 驱动的选品能力、精准投流优化、数据洞察和自动化运营，**帮助企业直接增加营收**，让企业赚更多钱。

### 核心价值主张

- **减少成本**：用 AI 数字员工替换传统人力岗位，降低企业人力成本
- **增加营收**：通过 AI 选品发现蓝海机会、通过智能投流提升 ROI、通过数据洞察优化经营策略
- **自动协同**：员工之间自动互通信息、协作接力，老板通过一个驾驶舱即可全局掌控
- **持续进化**：AI 在企业使用过程中不断学习优化，越用越贴合企业实际情况

## What Changes

本项目宪章定义了 AgentX 平台的完整产品边界、核心功能和实施路线。基于现有代码库（已具备 4 个 Agent、MCP 工具链、加密存储、JWT 认证等基础能力），完成以下工作：

- 明确产品定位：面向中小型国内电商企业的 AI 数字员工协作平台（减成本 + 增营收）
- 定义完整的 8 大电商职位角色矩阵与能力边界（新增供应链选品师、智能投流专员）
- 设计 Agent 间信息互通与协同工作的核心机制
- 规划企业老板全局驾驶舱的功能范围，支持移动端 PWA 访问
- 建立多租户安全隔离的完整规范
- 实现主流电商平台的 API 真实对接（抖音/淘宝/拼多多/蝉妈妈/生意参谋等）
- 实现 AI 自动进化机制（记忆巩固、经验积累、模型微调）
- 实现 Redis 消息队列的完整生产部署
- 直接配置 PostgreSQL 作为生产数据库
- 支持公司自定义 Agent 和每个 Agent 独立配置大模型
- 支持 Agent 复用 MCP 协议工具，调用外部软件完成实际工作
- 建立 Harness 工程标准（类型检查、Lint、CI/CD、安全扫描）
- 制定分阶段实施路线，每个阶段可独立交付和验证

## Capabilities

### New Capabilities
- `project-charter`: 项目宪章，定义产品愿景、目标用户、核心价值主张和全局功能范围
- `agent-roles`: 电商数字员工职位矩阵（8 个职位），定义每个职位的职责、能力、工具集、Skill 工作流、LLM 模型策略和协作关系
- `multi-tenant-isolation`: 多租户安全隔离，确保不同公司的数据、Agent、任务完全隔离
- `agent-collaboration`: Agent 间信息互通与协同工作机制（共享上下文总线、任务接力、三级审核机制、消息通知）
- `agent-evolution`: AI 自动进化机制（三层记忆系统、记忆睡眠巩固、模型微调、经验积累）
- `boss-dashboard`: 企业老板全局驾驶舱（PWA 移动端适配），一站式查看所有数字员工工作状态、数据看板、告警推送和关键指标
- `frontend-app`: 前端应用，提供登录、Dashboard、Agent 对话、任务管理、审核工作流、系统设置等完整用户界面
- `platform-requirements`: 平台功能需求清单，涵盖核心业务流程、平台 API 对接、企业自有 LLM Key、PostgreSQL/Redis 基础设施和 Harness 工程标准

### Modified Capabilities
无——本项目是新宪章的建立，不修改已有 spec（后续分阶段实现时会创建各自的 spec）。

## Impact

- **代码库**：不直接修改代码，建立产品方向共识。后续各阶段按本宪章创建独立的 change proposal
- **现有系统评估**：前序审计已发现的 4 个 P0 致命问题（JWT 默认密钥、公司隔离缺失、加密 Bug、硬编码 company_id）将作为前置修复条件
- **数据库迁移**：从 SQLite 直接切换为 PostgreSQL，需执行数据迁移和 ORM 适配
- **基础设施升级**：引入 Redis 替代内存队列，支持生产级消息队列和高可用部署
- **团队协作**：为所有后续开发提供统一的产品语言和决策依据

## 八职位全景

| 职位 | 类型 | 核心产出 | LLM 依赖 | 日均 Token 估算 |
|------|------|---------|---------|----------------|
| 品牌商务 | 保障型 | 达人筛选报告、邀约话术、效果复盘 | 高 | 80K |
| 内容运营 | 保障型 | 短视频脚本、内容排期、直播脚本 | 最高 | 120K |
| 数据分析 | 保障型 | 经营报表、异常告警、策略建议 | 中（MetricsEngine 零 LLM） | 40K |
| 客服专员 | 保障型 | 自动回复、售后处理、评价管理 | 中（RAG 增强） | 60K |
| 仓储物流 | 保障型 | 发货调度、物流跟踪、库存预警 | 低（LogisticsEngine 主导） | 20K |
| 视觉设计 | 保障型 | 主图/详情页/封面设计 | 高（多模态） | 100K |
| 供应链选品师 | 增长型 | 选品报告、利润测算、供应商评估 | 高（深度分析） | 70K |
| 智能投流专员 | 增长型 | 投放策略、素材优化、ROI 评估 | 高（实时优化） | 90K |

> 6 个保障型职位覆盖电商日常运营必备职能，2 个增长型职位直接驱动营收增长。企业可按需订阅。
